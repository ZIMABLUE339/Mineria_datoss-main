¿Qué es?

Un sistema de
análisis de datos globales

ODS Explorer es una plataforma web para explorar los indicadores de los Objetivos de Desarrollo Sostenible definidos por la ONU, usando datos oficiales del Banco Mundial.

El sistema permite filtrar por país, año e indicador, visualizar tendencias en gráficos interactivos y comparar el desempeño entre naciones.

La arquitectura aplica la metodología SEMMA en cada capa: desde la ingesta de datos CSV hasta la visualización con Chart.js y la API RESTful en Flask.

Metodología SEMMA

El proceso de minería de datos detrás del sistema

S

Selección

Carga del dataset ods_data.csv con indicadores del Banco Mundial. Filtros dinámicos por país, año e indicador seleccionan el subconjunto de análisis.

PASO 01
E

Exploración

Estadísticas descriptivas, detección de datos faltantes y visualización preliminar. El endpoint /api/statistics expone el resumen del dataset.

PASO 02
M

Modelado

Transformación de datos con Pandas: limpieza, agregación y cálculo de promedios cuando hay datos faltantes por año. La función filter_data() implementa este pipeline.

PASO 03
V

Visualización

Gráficos de barras, líneas y radar con Chart.js en el dashboard. Los datos fluyen desde la API Flask al frontend en tiempo real mediante fetch asíncrono.

PASO 04
A

Análisis / Evaluación

Comparación entre países mediante el endpoint /api/compare. Los KPIs del dashboard permiten evaluar el desempeño relativo de cada nación.

PASO 05
Stack

Tecnologías del sistema

Backend · Flask

Framework Python ligero con rutas REST, manejo de errores y servidor WSGI compatible con Gunicorn para producción.
