🚀 INICIO RÁPIDO
═══════════════════════════════════════════════════════════════

OPCIÓN 1: Script Automático
───────────────────────────
Windows:   Ejecuta INICIO_RAPIDO.bat
Mac/Linux: chmod +x INICIO_RAPIDO.sh && ./INICIO_RAPIDO.sh

OPCIÓN 2: Comando Manual
───────────────────────
1. Activar ambiente:
   Windows:   .venv\Scripts\activate
   Mac/Linux: source .venv/bin/activate

2. Ejecutar app:
   python app.py

3. Abrir navegador:
   http://localhost:5000


📤 DESPLIEGUE EN RENDER (5 MINUTOS)
═══════════════════════════════════════════════════════════════

1. Crear Repositorio GitHub:
   ├─ git init
   ├─ git add .
   ├─ git commit -m "Initial commit"
   └─ git push -u origin main

2. Configurar en Render.com:
   ├─ Conectar repositorio GitHub
   ├─ Build: pip install -r requirements.txt
   ├─ Start: gunicorn app:app
   └─ Variables: FLASK_ENV=production

3. URL en Vivo:
   └─ https://dashboard-ods.onrender.com

🐛 TROUBLESHOOTING RÁPIDO

❌ Datos no se cargan
✓ Verificar que data/ods_data.csv exista

❌ CSS/JS no funciona
✓ Ctrl+F5 (hard refresh del navegador)

❌ Puerto 5000 en uso
✓ Cambiar en app.py: app.run(port=5001)

❌ Error en Render
✓ Ver logs: Dashboard → Logs
